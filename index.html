Git Stash

9 comandos
ComandoFunciónUso Diario
git stashGuarda trabajo temporal sin commitear⭐ Cambio de rama urgente
git stash popRecupera el último stash y lo elimina⭐ Volver al trabajo
git stash save "desc"Guarda stash con nombre/mensaje⭐ Organización
git stash listVer todos los stashes guardados⭐ Saber qué tienes
git stash apply stash@{1}Aplica un stash específico SIN borrarlo⭐ Recuperar sin perder
git stash drop stash@{1}Borra un stash específicoLimpieza
git stash clearBorra TODOS los stashes⚠️ Usar con cuidado
git stash show stash@{0}Ver qué archivos hay en un stashRevisar antes
git stash branch rama stash@{0}Crear rama desde un stash⭐ Avanzado

Flujo de Trabajo Profesional

3 pasos
01
Crear rama de feature
git checkout -b feature/ticket-123
02
Trabajar y commitear
git add -p && git commit -m "feat: desc"
🎯 Un commit por cambio lógico
03
Mantener al día con main
git pull --rebase origin main
04
Subir y crear PR
git push -u origin feature/ticket-123
✨ Crear Pull Request en GitHub
05
Después del merge
git checkout main git pull --rebase git branch -d feature/ticket-123 git push origin --delete feature/ticket-123

Aliases que Aceleran tu Día

8 aliases

git config --global alias.tree "log --oneline --graph --all"
git unstage Sacar TODO del staging
git config --global alias.unstage "restore --staged ."
git last Ver último commit
git config --global alias.last "log -1 HEAD"
git undo Deshacer último commit
git config --global alias.undo "reset --soft HEAD~1"
git co Alias para checkout
git config --global alias.co checkout
git cb Crear y cambiar a rama
git config --global alias.cb "checkout -b"
git st Status corto
git config --global alias.st "status -sb"
git stash-list Ver stashes con nombres
git config --global alias.stash-list "stash list --pretty=oneline"

Pro Tips del Día a Día

6 consejos
🎯

Regla de oro del commit

Título ≤50 caracteres, imperativo presente, específico: "Fix NPE in UserService" NO "Fixed bug"

🔄

Antes de push

Siempre haz git pull --rebase para evitar merges innecesarios y mantener historia limpia

🆘

Si todo falla

git reflog es tu mejor amigo. Siempre puedes volver atrás desde ahí

📦

Stash profesional

Siempre usa git stash save "descripción" para identificar qué guardaste

🚀

Pull Request exitoso

Antes de crear PR: rebase interactivo para limpiar commits + git push --force-with-lease

⚡

Stash + rebase

git stash → git pull --rebase → git stash pop = Flujo perfecto

📦 Stash — Referencia Rápida
